01 / 长城汽车 HAVAL / Slides 02-29, 36-47

Great Wall Motor

长城汽车是作品集里体量最大的项目组，包含多个 HMI 与 3D 视觉子项目。网站中按 PPT 顺序拆成六个子模块：驾驶模式、改装厂、3D 桌面车模、SR Design、SR_POC、Driver Mode 动画。

01-A / Drive Mode / Slides 03-21

驾驶模式视觉设计

Sand、Offroad、Grassland、Snow、Concave convex、Highway 六种路况模式。每组内容对应场景视觉、整车渲染和 Kanzi 开发效果对比。

01-B / Modification Factory / Slides 22-24

改装厂场景设计

面向车载场景展示的三维改装厂空间，包含静态场景图和 2560*720 动画展示。

01-C / 3D Launcher / Slides 25-26

3D 桌面 / 车模效果设计

围绕座舱 3D Launcher 与车模效果展开，用车模视角建立桌面视觉中心和车辆展示方式。

01-D / SR Design / Slides 27-29

SR Design

长城汽车 SR 设计，展示高速路况和 Noon、Morning、Night、Dusk 四种时间状态。

01-E / SR_POC / Slides 36-45

SR_POC / 3D POC Design

连续的 SR 场景渲染专题，包含不同时间、天气、道路和交互状态下的可视化方案。

01-F / Driver Mode Motion / Slides 46-47

Driver Mode 动画

驾驶模式动画扩展，包含公路模式、涉水模式和石地模式三段视频。

02 / 腾势 Z9 / Slides 30-31

Racing Assistant

竞速助手是独立项目，围绕动态驾驶中的趣味感与性能反馈展开。内容包含竞速模式概念说明、界面视觉和一段动效。

03 / 江铃 POC / Slides 32-35

JMC 3D POC Design

江铃 POC 是一组动效设计集合，重点展示仪表入场、转场、空调吹风，以及泥地和沙地模式动画。

04 / 知行科技 SR / Slides 48-50

Zhixing SR

知行科技 SR 项目以驾驶辅助状态为核心，展示 Night mode、ALC 自动变道、NOA 开启、正在泊车和泊车完成。

05 / 滴水 OS SR / Slides 51-52

Dishui OS SR

滴水 OS SR 是独立动效展示项目，在 PPT 中以项目标题页和一段视频收尾，适合作为网站最后一个 Motion Case。
